# Londono Intelligence Standard

The Londono Intelligence Standard defines the minimum public principles for trustworthy intelligence systems.
These standards guide architecture, operations, and governance design.

## LS-01 Human Authority
Final decision authority belongs to accountable humans.
AI can inform decisions but does not own responsibility.

## LS-02 Model Replaceability
Models must be swappable without breaking core system intent.
Architecture should prevent lock-in and preserve continuity across model changes.

## LS-03 Reversibility
Material actions must be reversible when possible.
Systems should support rollback paths to reduce operational risk.

## LS-04 Auditability
Decisions and actions require traceable records.
Systems should maintain clear logs of inputs, approvals, and outcomes.

## LS-05 Institutional Memory
Key decisions, rationale, and outcomes must persist beyond individuals.
Organizations should retain decision context so meaning stays stable over time.
