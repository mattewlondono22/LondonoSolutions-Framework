## Content System Architecture

The content distribution system operates in five layers, derived from the LWS and Content Agency protocols.

---

### Layer 1: Intent Definition

Before any content is created, the intent must be declared.

**Required per content piece:**
- Target audience (Capital Operators / General / Internal)
- Primary decision to drive (Book a call / Follow / Inquire / Share)
- Channel(s) for distribution
- Doctrine alignment: which LS principle does this content reinforce?

**Rule:** No content enters production without a completed Intent Definition. If intent is fuzzy, content does not ship.

---

### Layer 2: Content Generation (Agent-Assisted, Human-Governed)

Content is generated using the Invictus / SmartAgents context as grounding.

**Agent responsibilities:**
- Draft long-form content (website pages, LinkedIn articles, thought leadership)
- Draft short-form posts (X, LinkedIn, Instagram captions)
- Propose calls-to-action
- Surface objections and address them in copy

**Human responsibilities:**
- Final wording and tone approval
- Truth and accuracy verification
- Brand voice enforcement
- Legal and ethical review

**Rule:** AI drafts. Humans decide. No content is published without human sign-off.

---

### Layer 3: Channel Formatting

Each channel has a defined format and constraint.

| Channel | Format | Constraint |
|---------|--------|------------|
| londonosolutions.com | Long-form pages, case studies, positioning copy | LWS five-layer structure enforced |
| LinkedIn | 150–800 word posts, articles | One primary insight per post. No fluff. |
| X (Twitter) | 280 character posts, threads | Direct. One idea. Provokes a decision. |
| Instagram | Image + caption (max 200 words) | Visual proof of work. One CTA. |

---

### Layer 4: Approval and Distribution

All content passes through the approval gate before distribution.

**Approval gate requirements:**
- Human owner review completed
- Intent Definition matched against final output
- Doctrine alignment confirmed

**Distribution protocol:**
- londonosolutions.com: Direct publish or via CMS
- LinkedIn: Manual post or scheduled via approved tool
- X: Manual post or scheduled via approved tool
- Instagram: Manual post or scheduled via approved tool

**Rule:** Scheduling tools are approved tools only. No third-party automation that bypasses human review.

#### Cross-Channel Feed System

The distribution system feeds all active channels from one governed post package.

**Shared source package:**
- Core claim
- Primary metric or proof point
- Target audience
- Primary CTA
- Channel variants (website, LinkedIn, X, Instagram)

**Flow:**
1. Create one approved source package inside the Content Agency workflow.
2. Adapt the package to each channel format without changing the governing claim.
3. Publish to londonosolutions.com first when the post requires a proof page, case framing, or destination link.
4. Distribute channel variants to LinkedIn, X, and Instagram within the same 72-hour operating window, beginning at the moment the source package receives final human approval.
5. Log every distribution event with date, channel, asset link, owner, and metric tag.

**Rule:** One source package can create many channel variants, but every variant must preserve the same doctrine alignment, proof point, and CTA.

---

### Layer 5: Metrics and Iteration

Every published piece is tracked. No content system runs without measurement.

**Metrics tracked per channel:**

| Channel | Metrics |
|---------|---------|
| londonosolutions.com | Page views, time on page, primary CTA conversion rate, inquiry form submissions |
| LinkedIn | Impressions, engagement rate, follower growth, profile visits, inbound connection requests |
| X (Twitter) | Impressions, engagement rate, follower growth, link clicks |
| Instagram | Reach, engagement rate, follower growth, profile link clicks |

**Cross-channel metrics:**
- Content-attributed inbound inquiries (tracked via UTM or direct attribution)
- Week-over-week audience growth across all active channels
- Publish cadence compliance: minimum 3 posts/week across all channels combined

**Iteration trigger:** If engagement rate drops below 1% for three consecutive weeks on any channel, content strategy is reviewed.

#### Attribution Protocol

To support Capital Operators positioning with proof, every distribution asset must be attributable.

**Required tracking fields:**
- `utm_source` = website, linkedin, x, instagram
- `utm_medium` = organic, direct, scheduled
- `utm_campaign` = smartagents_positioning, doctrine_signal, proof_of_work
- `utm_content` = time_saved, risk_reduction, decision_speed, case_framing

**Example tracking URL:**
- `https://www.londonosolutions.com/smartagents?utm_source=linkedin&utm_medium=organic&utm_campaign=smartagents_positioning&utm_content=time_saved`

**Required log fields:**
- Published date
- Channel
- Audience target
- Primary CTA
- Proof point used
- Inquiry or conversion outcome

**Review cadence:** Weekly channel review, monthly SITREP rollup.
